# 🗑️ Duplicate File Destroyer 3000

**WARNING:** This script is 100% serious… but also 0% actually useful on Windows.  

---

## What it does

- Scans a folder for “duplicate files”  
- Deletes the duplicates automatically  
- Prints a confirmation message for each file deleted  

**Meme Twist:**  
> You can never have duplicate files on Windows… so congratulations, this script is basically a “scanner of ghosts.” 🤪

---

## How to use

- python duplicate_destroyer.py

- Paste your folder path

- Watch the script try to find duplicates that literally cannot exist

- Smile at the irony

- Optionally delete files if AI or the script convinces you there are duplicates

## story behind this
I was just starting out, thinking it would be a simple practice project: write a script to find duplicate files in a folder. I spent some time coding, built the logic, and was ready to test it. My brilliant plan? Create a duplicate file by saving "something.txt" twice. That's when I had a facepalm moment: Windows won't let you create files with identical names in the same folder. So, I had created a solution for a problem that can't even exist on my own computer. My big idea ended up being a completely useless script, and I felt pretty silly about it.
